Unsupervised Anomaly Detection
Three independent ML methods applied to 9 state-level features. Consensus flags the most credible anomalies.
Methodology Note: These are unsupervised anomaly scores — no labelled ground truth exists at the state level, so precision/recall/F1 are not applicable here. The 3-method consensus approach minimises false positives. A CRITICAL flag does not constitute proof of misuse; it identifies states warranting further investigation.
Method A — Isolation Forest
Isolates anomalies via random tree partitioning. Lower score = more anomalous.
Method B — Local Outlier Factor
Compares local density to neighbours. LOF > 1.2 triggers a flag.
Method C — Z-Score Composite
Flags states where ≥3 features exceed |z| = 2.0 threshold simultaneously.

Methodology & Data Sources
How the BHCPF ML accountability pipeline was built — from raw disbursement records to facility risk scores.
Data Limitations: Population figures are NPC 2023 projections based on 2006 census growth rates — not a fresh census. EMTC (Emergency Medical Treatment Component) data was unavailable for Q1 and Q2; values set to zero. Q3 data was manually extracted from PDF sources. These limitations are disclosed to enable critical evaluation of the findings.
Pipeline Architecture — 4 Stages
1

Data Extraction & Cleaning

Raw BHCPF disbursement records for Q1–Q3 2025 loaded from Excel (Q1, Q2) and PDF extraction (Q3). Column harmonisation across quarters via clean_quarterly(). Canonical state name normalisation applied to all 37 states + FCT. Output: 111 clean disbursement rows.

2

Feature Engineering

Pivot table computes Q1/Q2/Q3 totals per state. QoQ growth rates and volatility derived. Facility data (8,309 records) aggregated to state level: functionality score, % non-functional, facility count. Shannon entropy applied to gateway diversity. Population normalisation via NPC 2023 figures. 9 final ML features. Output: state_features.csv (37 × 18).

3

Unsupervised Anomaly Detection

Three independent methods applied to standardised features: Isolation Forest (contamination=0.15), Local Outlier Factor (n_neighbors=5), and Z-score composite (|z| ≥ 2.0, ≥3 features). Consensus scoring (0–3) classifies states into CRITICAL, CONCERN, WATCH, or CLEAN tiers. No ground truth labels — unsupervised methods are appropriate here.

4

Random Forest Risk Model

Binary classification: AT RISK (PARTIAL + NON-FUNCTIONAL) vs FUNCTIONAL (L1 + L2). Class imbalance (86:14) handled with class_weight="balanced". 14 features including LGA encoding, state-level anomaly scores, and all engineered features. Evaluated on stratified 20% holdout. Output: risk score [0–1] for all 8,309 facilities.
